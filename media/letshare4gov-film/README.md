# LetShare4Gov — A more connected working day

An AI-generated, photorealistic live-action-style brand film for facilities
teams in public organisations. These are fictional scenes, **not recordings
of actual customers, employees or public officials**. The English narration
is synthetic. No testimonials or measured business outcomes are implied.

## Delivery

The film uses the same English narration and story in four compositions:

| File label | Aspect ratio | Output dimensions |
| --- | --- | --- |
| `16x9` | 16:9 | 1920 × 1080 |
| `9x16` | 9:16 | 1080 × 1920 |
| `1x1` | 1:1 | 1080 × 1080 |
| `4x5` | 4:5 | 1080 × 1350 |

Each composition is delivered twice: with Dutch (`NL`) or European Portuguese
(`PT`) subtitles burned into the picture. `EN` in the filename identifies the
spoken language, not the subtitle language. MP4 files use H.264 video, AAC
audio, and web-friendly fast-start metadata.

The final export manifest is generated by the render pipeline. It records the
actual duration and output paths. The intended runtime is approximately
77 seconds. Separate SRT and WebVTT files use the same timeline.

| 04 | Colleagues aligning around a laptop | A shared overview for facilities work |
| 05 | Preparing a meeting room | Room and workspace reservations |
| 06 | Technician inspecting a building fixture | Issue reporting and planned maintenance |
| 07 | Welcoming an adult visitor | Visitor registration and reception preparation |
| 08 | Colleagues reviewing folders | Organised contracts and documents |
| 09 | Focused work at a desk | Open requests and recent activity |
| 10 | Colleagues walking through a civic atrium | More focus on people, spaces and services |

`script.json` contains the English recording text and the Dutch and European
Portuguese translations. “LetShare for Gov” in the recording text is a
pronunciation instruction for the synthetic voice. The written brand name
remains **LetShare4Gov** everywhere in the film.

## Sources and scope of claims

Product statements were checked against the current product implementation:

- Issue reporting and ticket status: the app's `meldingen` pages.
- Room/workspace reservations: room pages and the reservations API.
- Planned building maintenance: the MJOP page and API.
- Visitor registration: the visitors page.
- Contracts and documents: the contracts page and API.
- Open requests and recent activity: the dashboard page.

These are feature descriptions, not promises of savings, certification,
security guarantees or compliance. No personal data from the app is included.
Generated scenes do not show a fabricated product interface.

  `attached_assets/generated_audio/letshare4gov/score.mp3`.

## Rebuilding

Run from the workspace root with Python 3 and FFmpeg/ffprobe available:

```sh
python3 media/letshare4gov-film/render.py
python3 media/letshare4gov-film/verify.py
```

The pipeline needs all generated source clips, narration segments, score,
original logo and the local licensed Inter font. Missing or invalid inputs
are errors, not grounds to silently substitute still images or low-resolution
footage. Keep the source media and manifests together for later edits.
